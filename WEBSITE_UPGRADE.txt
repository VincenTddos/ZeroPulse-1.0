【快速預覽】

✨ 在瀏覽器中預覽:

方法 1 - 直接開啟檔案:
  1. 打開 c:\Users\User\Desktop\zeropulse.club\website\index.html
  2. 在瀏覽器中預覽

方法 2 - 使用 Python HTTP 伺服器:
  1. CMD: python -m http.server 8000
  2. 訪問: http://localhost:8000/website/

方法 3 - 用 VS Code Live Server 擴充:
  1. 在 website/ 資料夾右鍵
  2. 選「Open with Live Server」
  3. 自動在瀏覽器開啟

【部署到線上】

0. 本地測試完畢後:

1. Vercel 部署 (免費)
   a. 進 vercel.com
   b. 選「New Project」
   c. 導入 GitHub 倉庫
   d. 設定 Root Directory: website/
   e. 部署 → 自動上線

2. 自訂域名 (可選)
   a. Namecheap 買 zeropulse.club
   b. Vercel 設定 → 加入域名
   c. 更改 DNS 指向 Vercel
   d. 等待 24hr DNS 生效

3. API 連接 (可選)
   a. website/script.js 更新 API URL
   b. 改為你的 Railway API 位址
   c. 重新部署

【常見問題】

Q: 網站太慢?
A: 檢查網路。CSS 只有 600 行，很輕量。
   也可壓縮 CSS (去除空格)。

Q: 顏色太亮?
A: 改 style.css 的 #00ff88 為其他顏色。
   推薦: #ff6600 (橙), #6666ff (藍), #ff0099 (粉紅)

Q: 想加 Logo?
A: 在 logo div 加 <img>:
   <div class="logo"><img src="logo.png" alt="ZeroPulse"></div>
   記得改 CSS 的 .logo 高度

Q: 想改 Discord 連結?
A: 搜尋 "https://discord.gg/zeropulse"
   改成你的邀請連結
