【⚡ 快速命令】

進入專案目錄:
  cd c:\Users\User\Desktop\zeropulse.club

啟動 GUI:
  python client/gui.py

啟動 API (可選):
  cd server && npm install && npm start

啟動網頁伺服器 (預覽網站):
  python -m http.server 8000
  → 訪問 http://localhost:8000/website

打包 EXE:
  pyinstaller --onefile --windowed --name "ZeroPulse" client/gui.py
  → 輸出在 dist/ZeroPulse.exe

安裝依賴:
  pip install -r requirements.txt

【❓ 需要幫助?】

常見問題:
  → 看 README.md 或 docs/DEPLOY_GUIDE.md

GUI 無法開啟:
  → 檢查 Python 版本: python --version (需 3.8+)
  → 安裝依賴: pip install pyautogui psutil

序號驗證失敗:
  → 用測試序號: ZP-M-TEST-1234
  → 檢查 server/index.js 中的 validSerials

網站無法顯示:
  → 用 Python 伺服器: python -m http.server 8000
  → 訪問 http://localhost:8000/website/index.html

API 無法連線:
  → npm install (安裝依賴)
  → npm start (啟動伺服器)
  → 訪問 http://localhost:3000/health
