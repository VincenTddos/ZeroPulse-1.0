【開始使用 (3 種方式)】

【方式 1】- 本地 GUI 測試 (推薦)
  1. 打開 CMD 進入: c:\Users\User\Desktop\zeropulse.club
  2. 輸入: python client/gui.py
  3. GUI 彈出 → 點「驗證序號」 → 輸入 ZP-M-TEST-1234
  4. 激活成功！

【方式 2】- 一鍵啟動 (最簡單)
  1. 雙擊 run_gui.bat
  2. 自動安裝依賴 + 開啟 GUI
  3. 完成！

【方式 3】- 測試網站
  1. 打開瀏覽器進入: http://localhost:8000/website
     (需先跑: python -m http.server 8000)
  2. 點「立即購買」查看方案
  3. 點「登入」驗證序號

【打包成 EXE 賣給客戶】

Step 2: 複製 dist/ZeroPulse.exe 到任何位置

Step 3: 發送序號給客戶
  → 客戶執行 ZeroPulse.exe
  → 貼入序號 → 激活 → 開始壓槍！

【部署到線上 (真實賣)】

分 3 個步驟:

【Step 1】- 部署網站 (Vercel - 5分鐘)
  1. 進 vercel.com 註冊
  2. 選「Deploy」→ 導入 website/ 資料夾
  3. 自動部署 → 得到 zeropulse.vercel.app
  4. (可選) 在 Namecheap 買 zeropulse.club 域名

【Step 2】- 部署 API (Railway - 5分鐘)
  1. 進 railway.app 註冊
  2. 新增專案 → Deploy from GitHub
  3. 選本倉庫 + server/ 資料夾
  4. 自動部署 → API 上線

【Step 3】- 配置 DNS (5分鐘)
  1. Namecheap 設定 DNS 指向 Vercel
  2. website/.js 修改 API URL 為 railway.app
  3. 完成！網站自動連接雲端驗證

【常見問題解答】

Q: 私人伺服器用安全嗎?
A: 100% 安全。無 EAC 的私人伺服器沒有任何檢測風險。

Q: 官方服呢?
A: 用 Randomness 15%+ (人化抖動)，像真人打法，風險極低。
   但謹慎使用，別連贏 10 把 (容易被舉報)。

Q: 可以給多個朋友用嗎?
A: 不行。序號綁定 HWID (主機板序號)，一序號一電腦。
   需要多人用，聯絡客服購買團隊方案。

Q: 序號掉東西怎麼辦?
A: 提供 HWID，驗證身份後可重新激活。
   紀錄在 server/index.js 的 validSerials。

Q: 多久更新一次?
A: 每個 Rust wipe (週四) 或有重大平衡改動時更新彈道。
   終身版永遠免費更新。

Q: 能加硬體 (ESP32) 嗎?
A: 可以！等 ESP32 到貨後升級到 ZeroPulse 1.5 (硬體版)。
   現在用軟體版先賺第一桶金！
