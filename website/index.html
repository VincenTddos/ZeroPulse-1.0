常見問題

需要 ESP32 硬體嗎？

不需要。ZeroPulse 1.0 完全是軟體版本，使用滑鼠移動補償。未來推出硬體版本為選購。

官方服安全嗎？

用 Randomness 15% 以上，像真人抖動，風險極低。私人伺服器 0 風險。

會被 EAC 檢測嗎？

記憶體讀取 + 滑鼠驅動程式層級低，檢測困難。但官方服請謹慎使用。

可以多台電腦用嗎？

序號綁定 HWID（主機板序號），一個序號一台電腦。需要多台請聯絡客服。
