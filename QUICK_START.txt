  ZeroPulse 1.0 - 30秒快速上手指南
================================================================

【本地測試】
1. 雙擊 run_gui.bat
   → 自動安裝依賴 + 開啟 GUI

2. 或手動執行:
   cd client
   pip install pyautogui psutil
   python gui.py

【測試序號】(複製貼入登入)
- 月費: ZP-M-TEST-1234
- 季費: ZP-Q-TEST-5678  
- 終身: ZP-L-TEST-9999

【打包 EXE】
1. 雙擊 build.bat
   → 自動生成 dist/ZeroPulse.exe

【網站預覽】
1. 瀏覽器開啟: file:///c:/Users/User/Desktop/zeropulse.club/website/index.html
   或用 Python 伺服器:
   python -m http.server 8000
   訪問: http://localhost:8000/website

【線上部署】
- 前端 (網站): Vercel.com (免費)
- 後端 (API): Railway.app (免費)
- 域名: Namecheap (NT$300/年)

詳細教學: 看 docs/DEPLOY_GUIDE.md
